# Double pendulum

The four-state gravitational model is implemented in
[`chaos_toy_models.mechanics`](../../../src/chaos_toy_models/mechanics.py). Its
phase space is four-dimensional; the figure includes a labelled 3D projection
using `(theta_1, omega_1, theta_2)` and colour to encode time. It is a
projection of the full state space, not a claim that the system has a
three-dimensional Lorenz-style attractor. The same projection is available as
a rotating GIF in `figures/double-pendulum-rotation.gif`.
