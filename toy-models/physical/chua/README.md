# Chua circuit

The Chua circuit is a minimal autonomous electronic system with a
piecewise-linear nonlinear resistor. Its three state variables are normalized
capacitor voltages and inductor current; they are dimensionless in this toy
implementation.

Generate the figure with:

```bash
python toy-models/physical/chua/plot.py
```

The script also writes a rotating camera render to
`figures/chua-attractor-rotation.gif`.
